# Cendre & Acier — JDR Necromunda

Cendre & Acier est un projet de jeu de rôle inspiré de l'univers de Necromunda et de Warhammer 40,000. Ce site regroupe les informations nécessaires pour découvrir l'univers et préparer des parties de jeu de rôle dans un monde sombre, industriel et dangereux.

## Les différentes pages

- **index.html** : page d'accueil du site.
- **classes.html** : présentation des classes de personnages.
- **peuples.html** : présentation des différents peuples.
- **equipement.html** : informations sur les armes et les équipements.
- **dangers.html** : présentation des dangers et des menaces.
- **regles.html** : règles et mécaniques du jeu.
- **historiques.html** : contexte historique et éléments narratifs.
- **style.css** : feuille de style utilisée pour la mise en forme du site.
- **favicon.png** : icône du site.

## Technologies utilisées

- **HTML5** : structure et contenu des pages web.
- **CSS3** : mise en forme et apparence du site.
- **Git** : gestion des versions du projet.
- **GitHub** : hébergement du code source et suivi des modifications.

## Installation

Pour consulter le site en local, téléchargez ou clonez le dépôt GitHub, puis ouvrez le fichier `index.html` dans un navigateur web.

Dépôt GitHub : https://github.com/KiritoK999/Cendre-et-Acier-JDR-Necromunda
